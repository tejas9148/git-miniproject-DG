# Gitflow Release Cycle

This project simulates a complete software release cycle using Gitflow.

The project demonstrates feature development, releases, and production hotfixes.

## Gitflow Branch Types

- `main` contains production-ready code.
- `develop` contains the latest integrated development work.
- `feature/*` branches are used to develop individual features.
- `release/*` branches are used to prepare a version for production.
- `hotfix/*` branches are used to fix urgent production issues.
